1. ECSとは

ECS は、イベントの案件と、そこに入る社員・スタッフのアサイン（誰がどの現場に入るか）を、ひとつの場所で管理するための社内システムです。

これまで、案件情報・募集・連絡・アサイン表などが複数の場所（スプレッドシート／LINE／プロキャス等）に分かれていて、情報のズレが起きやすい状態でした。ECS は「情報を1か所に集めて、見える・記録する」ことを目的にしています。

※ 当日の連絡や確定の合図（LINEグループ招待など）は、これまでどおり LINE・チャットワークで行います。ECS は「見せる・記録する」役割です。

2. 誰が使う・何ができる（4つの権限）

ログインする人は、役割によって見える画面・できる操作が変わります。

権限主な人できること
スタッフ現場のバイト自分の確定アサインの確認、参加希望の入力、自分のプロフィール編集
社員営業・運営など案件の登録・編集・閲覧、アサイン、案件の削除まで
管理者アサイン担当社員のことに加えて、アカウントの発行・名簿の一括取込
Administrator全体管理すべての操作（マスタ・アカウントの削除、権限の付与、システム設定）

※ 権限は上にいくほどできることが増えます。スタッフは自分に関係することだけ、という考え方です。

3. 主な機能（できること）

案件まわり

  • 案件一覧・登録：イベント案件を登録し、一覧で確認・編集。CSVでまとめて取り込みも可能。
  • ダッシュボード：件数の集計や、日程が近い・重なっている「危険日」をカレンダーで確認。

アサイン（誰をどの現場に）

  • アサイン表：案件と割り当てメンバーを1画面でまとめて確認。
  • D決め・手動アサイン：ディレクターを決め、案件ごとに人を割り当てて保存。同じ日のダブルブッキングや、必要人数の過不足を色で確認。
  • スタッフ公開ボード：確定したアサインを「公開」すると、担当スタッフの画面に表示される。

名簿・希望

  • スタッフ／社員名簿：登録された人の情報・稼働状況を確認。CSVで一括登録も可能。
  • 参加希望・出勤可能日：スタッフ・社員が入れる日を入力・集約。

スタッフ側の画面（スマホ想定）

  • スタッフ用ポータル：自分の確定アサイン・お知らせ・締切を、スマホで見やすく表示。
  • マイページ：自分の担当した案件をカレンダーで確認。

そのほかの便利機能

  • 人数確定リマインド：開催が近い案件を、担当へチャットワークで自動お知らせ。
  • 謎解きの紙 在庫：必要枚数・消費・在庫を自動で集計。
  • 共通設定：コンテンツ・拠点などのマスタ管理、アサインMTGの予定管理。

4. 基本の流れ

ふだんの使い方は、おおまかにこの順番です。

  1. 案件を登録する（営業・運営）— イベントの案件を ECS に入れる。
  2. 希望を集める — スタッフ・社員が「入れる日」を入力する。
  3. アサインを決める（アサイン担当）— ディレクターを決め、案件ごとに人を割り当てる。
  4. 確定して公開する — 内容が固まったら「公開」にして、スタッフに見えるようにする。
  5. スタッフが自分の担当を確認 — スタッフはスマホで自分の確定アサインを見る。

5. ログインの仕方（2段階認証）

ECS には 顧客の社名などの情報が入るため、ログインは2段階認証で守ります（パスワードに加えて、メールに届く確認コードが必要）。

  1. アカウントは管理者が発行 — 自分で新規登録はできません。管理者が発行し、仮パスワードを受け取ります。
  2. メールアドレスとパスワードでログイン — ログイン画面で入力します。
  3. メールに届く6桁コードを入力 — 登録メール宛にコードが届くので、画面に入力します。10分間有効
  4. 初回は初期設定 — 初めてのログイン時は、パスワードの変更と、身長・靴のサイズなどのプロフィール入力をお願いします。
コードが届かないときは：入力画面の「コードを再送する」を押すと、新しいコードが届きます。パスワードを忘れたときの再発行も、今後メールで対応予定です。

6. テスト環境の試し方（4つの権限を体験）

テスト環境では、アカウント発行や2段階認証なしで、4つの権限をワンクリックで体験できます。役割によって見える画面がどう変わるかを確認できます。

  1. 上の「ECS を開く」からログイン画面を開く。
  2. 画面の「テスト用ログイン」から、試したい役割のボタンを押す（パスワード入力は不要・押すだけ）。
  3. ログイン後、左メニューや各画面を触ってみる。役割によって見えるメニューが変わります。
  4. 別の役割を試すときは、左メニュー下の「ログアウト」を押してから、別のボタンを選ぶ。
押すボタン権限ログイン後に見えるもの
スタッフスタッフ自分の確定アサインだけ（スマホ想定のスタッフ画面）
社員社員業務画面（案件・アサインなど。削除やマスタ操作は不可）
管理者管理者社員に加えて、アカウント発行・名簿CSV取込
AdministratorAdministratorすべての操作（削除・権限付与・設定）

初回ログインも体験できます：「🆕 初回ログインを体験」ボタンを押すと、管理者に発行された直後のスタッフとして、パスワード設定＋プロフィール入力の流れを体験できます。

※「テスト用ログイン」ボタンは体験用です（本番公開前に外します）。本物のログイン（メールアドレス＋パスワード＋メールに届くコード）は「5. ログインの仕方」をご覧ください。

役割ごとに見てほしいこと（フィードバックの観点）

  • スタッフ：自分の確定アサインや希望の出し方が、スマホで分かりやすいか。
  • 社員：案件の登録・一覧・編集がスムーズか。
  • 管理者（アサイン担当）：アサインの流れ（D決め → 手動アサイン → 公開）が回せそうか。
  • Administrator：アカウント発行・共通設定・名簿まわりが分かりやすいか。

いまの状況
