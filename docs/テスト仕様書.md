# ECS テスト仕様書

- 版：v0.1（初版）
- 作成日：2026-07-14
- 対象：ECS 全機能（別紙「テスト計画書」に基づく）
- 凡例：
  - レベル … **UT**=単体テスト / **IT**=結合(Feature)テスト / **ST**=システム(手動シナリオ)テスト
  - 重要度 … 高 / 中 / 低
  - 結果欄 … 実施時に 合格 / 不合格 / 保留 を記入

> 認証・権限（Sec.1）は Breeze/Fortify 移行完了後に実施する（計画書フェーズ3）。それ以外は移行前でも、テスト用ログインヘルパで実施可能。

## 付録：既知課題との対応表（重点検証ポイント）
