## はじめに

### 誰がどの画面を使えるか（権限4段階）
権限は弱い順に **スタッフ → 社員 → 管理者 → Administrator（全権）** の4段階です。

- **スタッフ**：自分専用の「スタッフ画面」だけを使います。業務用の画面には入れません（入ろうとすると自分の画面に戻されます）。
- **社員**：ダッシュボード・案件・アサインなど、ほとんどの業務画面を使えます。
- **管理者**：社員の画面に加えて「アカウント発行」「CSV一括取込」が使えます。
- **Administrator**：さらに「権限の付与・変更」「マスタの削除」ができます。

### ログインの流れ（3つの関門）
ログインすると、業務画面に入る前に次の順で確認があります。
1. **ログイン**（メール＋パスワード）
2. **2段階認証**（メールで届く6桁コード）
3. **初回設定**（発行されたてのアカウントだけ。パスワードとプロフィールを登録）

### テスト用ログインについて（開発中だけ）
ログイン画面には、ワンクリックで各権限を試せる「テスト用ログイン」ボタンがあります（パスワードは全部 `test`）。これは開発中の確認用で、**本番公開前に無効化します**。テスト用アカウントは2段階認証を飛ばし、プロフィールなどの保存も行われません（見本のため）。

### 「自分」はいま baba さん固定
本物のログイン連携が一部の画面ではまだ途中のため、「マイページ」と「収支入力」では **自分＝社員 baba さん** に固定されています。本番のログイン連携後に、ログインした本人へ切り替わります。

## 1. ログイン・本人の設定

### 1-1. ログイン画面（`/`）
**何のための画面か**：ECSに入るための入口です。登録済みのメールとパスワードで本人確認します。

**開き方**：ブラウザでトップ（`/`）を開く。ログインせずに他の画面を開こうとしても、自動でここに戻ります。

**使い方の手順**
1. 「メールアドレス」に自分のメールを入れる
2. 「パスワード」を入れる
3. 必要なら「ログイン状態を保持する」にチェック（次回から入力を省ける）
4. 「ログイン」を押す
5. このあとメールで届く6桁コードの入力へ進む

**つまずきポイント・注意**
- **在籍中の人しかログインできません**（退職などで無効になった人は入れません）。
- メールかパスワードが違うと「メールアドレスかパスワードが違います。」と出ます。
- **短時間に5回失敗するとロック**されます（1分あたり5回まで）。
- 「新規登録」は置いていません。アカウントは管理者が発行します。
- 画面下のテスト用ログインは本番前に消えます。

### 1-2. 2段階認証（`/otp`）
**何のための画面か**：なりすまし防止のため、メール＋パスワードの後にもう一段の本人確認をします。

**使い方の手順**
1. 登録メールに届いた6桁コードを確認
2. 「確認コード（6桁）」に入力
3. 「ログイン」を押す

**画面の要素**
- 「コードが届かない場合は再送する」：新しいコードを作り直して再送します。
- 「ログインし直す」：一度ログアウトして最初からやり直します。
- 画面下に「どのメール宛に送ったか」が出ます。

**注意**
- **コードの有効期限は10分**。過ぎたら「再送」でやり直し。
- **入力は5回まで**。間違えすぎたら「再送」でやり直し。
- 開発環境ではメールは実際には飛ばず記録に残るだけ（本番はメールで届きます）。
- テスト用アカウントはこの画面を飛ばします。

### 1-3. 初回設定・オンボーディング（`/onboarding`）
**何のための画面か**：発行されたてのアカウントで初めて入った人が、パスワードを決めて、自分の情報を登録する「最初の1回だけ」の画面です。

**使い方の手順**
1. 新しいパスワードを8文字以上で決める（確認欄にもう一度）
2. 氏名を確認・修正（必須）
3. メール・身長・靴サイズ・服サイズ・都道府県・最寄り駅・事務所を（任意で）入れる
4. スタッフは「一言アピール」も入れられる
5. 「設定を完了して始める」を押す

**注意**
- **パスワードと氏名は必須**。他は後から「マイプロフィール」で直せます。
- 一度終えると次回からこの画面は出ません。
- テスト用アカウントは保存されず、体験だけして先へ進めます。

### 1-4. プロフィール編集（`/profile`）
**何のための画面か**：ログイン中の本人が、自分のプロフィールを更新する画面です。当日の衣装準備やメンバー決めの参考になります。

**開き方**：左メニュー下部の「マイプロフィール」、またはスタッフ画面の設定タブから。

**入力できること**
- 共通：氏名（必須）・メール・事務所・身長・靴サイズ・服サイズ・都道府県・最寄り駅
- 社員だけ：所属（イベプラ／セールス／クリエイティブ）
- スタッフだけ：一言アピール・好き/苦手なコンテンツ・得意/苦手なポジション・「前泊後泊OK」・「着ぐるみOK」

**注意**
- 自分の役割（社員/スタッフ）で入力欄が変わります。
- テスト用アカウントは保存できません。
- ※スタッフ画面（`/staff-portal`）の設定タブにも似た入力欄がありますが、そちらはこのブラウザに一時記憶するだけです。**本物の保存はこの `/profile` の方**です。

### 1-5. パスワード変更（`/password`）
**何のための画面か**：本人が自分のパスワードを変えます。安全のため今のパスワードを先に確認します。

**使い方の手順**
1. 現在のパスワードを入れる
2. 新しいパスワードを8文字以上で入れる（確認欄にもう一度）
3. 「パスワードを変更」を押す

**注意**：現在のパスワードが違うと変更できません。テスト用アカウントは変更不可。

## 2. スタッフ画面
（`/staff-portal`）

**何のための画面か**：スタッフ本人専用の画面です。サイドバーの無い独自レイアウトで、4つのタブ（募集中の案件・稼働希望・確定アサイン・設定）で操作します。

**開き方**：スタッフはログインすると自動でここに来ます。

**タブごとの使い方**
- **📋 募集中の案件**：お知らせを読み、キーワード・エリア・状態・日付で絞り込んで、案件にコメントやエントリー（応募）ができます。
- **📅 稼働希望**：カレンダーの日をタップして「終日〇 → NG → 未定」を切り替え、コメントを添えて提出します。
- **✓ 確定アサイン**：担当が「公開」した、自分の担当案件だけが並びます。
- **⚙️ 設定**：プロフィール／できるポジション・スキル／アカウント（メール確認・プロフィール編集・パスワード変更・ログアウト）。

**重要な注意**
- **確定アサインに出るのは「担当が公開ONにした」かつ「あなたがアサイン済み」の案件だけ**です。応募しただけ・調整中は出ません。
- **稼働希望の提出は本物になりました**。カレンダーで入れた内容がそのまま保存され、担当側の集計にも反映されます。
- **設定タブのプロフィール・できるポジションの保存も本物になりました**（この画面で保存すると本人の名簿情報に反映されます）。「マイプロフィールを編集する」ボタン（→ `/profile`）からでも同じことができます。
- **エントリー（応募）も本物になりました（2026-07-17）**。案件へ「エントリー」すると一言コメントと一緒に保存され、取り消しもできます。担当側の「エントリー一覧」にも反映されます。
- 「ログアウト」「パスワード変更」「プロフィール編集」リンクは本物です。
- ※テスト用アカウントで試したときだけは、稼働希望やプロフィールは保存されません（見本のため）。

## 3. 毎日見る画面

### 3-1. ダッシュボード（`/dashboard`）
**何のための画面か**：会社全体の案件の「今どのくらい忙しいか」をひと目で見る画面です。ログイン後に自動で開きます。

**使い方の手順**
1. 上の4つの数字カード（今月・今週・大型・来月）でボリュームをつかむ
2. 「危険日カレンダー」で赤いマスがないか確認する
3. 「‹」「›」で月を移動。マスにマウスを乗せるとその日の案件の中身が出る
4. 「件数集計」で月を選ぶと拠点別・種別別の表が見られる

**危険日とは**：次のどれか1つでも当てはまる日です。
- 大型案件が同じ日に2件以上
- リアル系の案件が同じ日に5件以上
- その日に必要なスタッフ合計が28名以上（稼働40名の7割）

**注意**：画面に「モックです」という帯が出ますが、数字カードと危険日カレンダーは**実際の案件データで動いています**。件数集計表だけは分類のデータが揃っておらず暫定です。稼働人数「40名」は今は仮の固定値です。

### 3-2. マイページ（`/mypage`）
**何のための画面か**：自分が関わる案件を月ごとに一覧する個人ページです。自分の予定をGoogleカレンダーに登録したり、通知設定を切り替えたりもできます。

**使い方の手順**
1. プロフィールで自分の情報を確認（今は baba さん固定）
2. 「月で絞り込み」で月を選ぶと、下の2つの一覧（アサイン／営業担当）が同時に絞られる
3. 「アサインされた案件」で担当役割・集合解散・会場を確認。今後の案件は「📅登録」でGoogleカレンダーへ
4. 終了案件は「アーカイブ」から確認、「💰収支入力」へ
5. 「営業担当の案件」で自分が営業の案件を確認
6. 必要なら「通知設定」を切り替えて保存

**注意**
- 今はログイン未接続のため **baba さんを自分として表示中**です。
- **通知設定（新人フォロー所感／アサイン確定／締切のオンオフ）の保存は本物になりました（2026-07-17）**。切り替えて保存すると本人の設定として残ります。
- 「プロフィール編集」「パスワード変更」ボタンはダミーです（本物はメニュー下部から）。
- カレンダー登録は「予定追加画面が開く」半自動です。

### 3-3. 収支入力（`/mypage-finance`）
**何のための画面か**：自分が担当する案件ごとに、売上と経費を入れて利益（売上−経費）を出す画面です。

**使い方の手順**
1. 上の「月」と「案件」で対象を選ぶ
2. 「売上（受注額）」を入れる
3. 経費表で、単価が決まっている行は「数量」を、実費行は「金額」を入れる（合計と利益が自動計算）
4. 「この案件の収支を保存する」を押す

**注意**
- 入力できるのは **自分がディレクター（D）または営業担当の案件だけ**です。
- 「当日スタッフ費」の数量には、案件の運営人数が仮で自動入力されます（手で直せます）。
- 実費項目は1,000円単位に切り上げて合計されます。
- **保存は本物になりました（2026-07-17）**。売上・経費の明細まで保存され、次に開き直すと前回入力した内容が戻ります。

## 4. 案件

### 4-1. 案件一覧（`/projects`）
**何のための画面か**：登録済みの案件を一覧で見て、確認・編集・削除・アサインへの受け渡し・アサイン表への書き出しを行う「案件の司令塔」です。開催日の近い順に、年月ごとにまとまって表示されます。

**使い方の手順**
1. 上の絞り込みバー（キーワード・確度・実施形態・toC/toB・ケータリング・日程種別）で表を絞る
2. 「案件一覧／下書き／🗄アーカイブ」タブで表示範囲を切り替え（開催日が過ぎた案件は自動でアーカイブへ）
3. 行をクリックすると下に詳細が開く
4. 行右の「アサイン」「編集」「🗄アーカイブ」「削除」で操作
5. 左メニューの年月フォルダでその月へジャンプ

**主なボタン**
- 「📤 アサイン表へ書き出し」：月を選び、スプレッドシートに貼り付ける表（タブ区切り）を作ってコピー
- 「⬆ CSVで取込」：案件CSV取込へ
- 「＋ 案件を登録」：新規登録フォームへ
- 行の「アサイン」：手動アサイン画面へ／「編集」：登録内容が入った編集フォームへ

**詳細パネルの編集について（2026-07-17 で本物に）**
- 詳細パネルのプルダウンのうち **ディレクター・SD・物品担当・移動・音響は本物で保存されるようになりました**。プルダウンには実際の社員が並び、**1つ直すたびにその項目だけ保存**されます（他の項目は消えません）。**SD担当も選んで保存でき、「未設定」固定は解消**しました。
- **手動の「🗄アーカイブ」も本物で保存されます**。開催日が過ぎた案件は自動でアーカイブされますが、手動でアーカイブ／戻すと、そちらが優先されます。
- ケータリング（種類＋メモ）は従来どおり本物で保存されます。
- 「削除」は元に戻せません。関連するアサインや、その案件を親にした予備日・リハ日も一緒に消えます。
- ※準備チェックや運営シート作成など、一部の欄はまだ見本のままです。

### 4-2. 案件登録・編集フォーム（`/project-form`）
**何のための画面か**：イベント案件を1件ずつ手入力で登録（＆編集）する画面です。項目が多いので、色分け（赤＝必須で空／黄＝後で必要／白＝入力済み）で埋めるべき欄がわかります。

**開き方**：新規は一覧の「＋案件を登録」。編集は行の「編集」（`?project=案件ID`）。

**使い方の手順**
1. 上部タブで「✎1件ずつ入力」を選ぶ
2. 「基本情報 → 当日・手配情報 → 備考」の順に入力。赤い欄は必ず埋める。今すぐ決まらない欄は「未定／仮」チェックを使う
3. 下部の「下書きとして保存」か「確定」を押す。危険日に当たると保存前に警告が出る
4. 「複数案件＝あり」や「予備日・リハとして登録」にすると「＋同じ内容で次の日程を追加」が出る

**入力欄のポイント（一部）**
- 区分（通常案件/追加案件）：アサインMTG日を基準に自動で初期選択、手動変更も可
- 確度（ヨミ）：確定以外を選ぶと「確定見込み時期」欄が開く
- 案件名（コンテンツ）：検索して複数選択、無ければ入力して追加。これが案件名になる
- 実施形態：「オンライン」でツール欄、「他拠点」で対象拠点欄、「ARENA」で専用7項目が開く
- 集合・解散時間：両方入れると拘束時間を自動計算（9時間超でリアルロングの目安）

**注意**
- 必須3点（**案件名・開催日・運営人数**）は、値を入れるか対応する「未定/仮」チェックを入れないと保存に進めません。
- 「いつ頃?」などの補足メモ欄は保存されません（画面上の補助メモ）。
- 危険日警告は確認だけで、保存は止めません。
- この画面では**ディレクター・物品担当・SD・準備チェック・スタッフ公開用時間は保存されません**（別の画面で設定します）。

### 4-3. 案件CSV一括取込（`/project-import`）
**何のための画面か**：記入済みのCSV（Excelの表）を読み込み、複数の案件を一度に登録します。

**使い方の手順（5ステップ）**
1. 「テンプレート.csv」をダウンロードし、Excelで1行1案件を記入
2〜3. 記入したCSVをドラッグ＆ドロップ、または「ファイルを選択」
4. 自動チェックの結果（読み込み行数・取込可能件数・エラー件数）と表を確認。エラー行は赤くなり、クリックすると1件ずつ登録画面が開いて直せる
5. 「この内容で取り込む」でOK行だけ登録

**必須項目**：案件名・開催日（YYYY-MM-DD の実在日）・運営人数（1以上）。これが揃わない行は取り込まれません。

**注意**
- 列の順番は入れ替えてもOK（見出し名で対応づけ）。ただし見出し名は一致が必要。
- 「運営」グループ（ディレクター・物品担当・運営シート・準備チェック）は空欄でOK。
- ARENA場所貸しは専用項目が多いので「1件ずつ入力」推奨。
- 「サンプルデータで試す」は登録されない確認用です。

## 5. アサイン

> アサインは複数の画面から行えます。**保存はほぼ全画面で本物になりました**：「手動アサイン」「日別ボード」「エントリー一覧の月ごと表」「アサイン表」「ピックアップ」「D決め」「スタッフ公開ボード」。以前は見本だった「日別ボード」「ピックアップ」の割り当ても保存されます。残る見本は、日別ボードの「確定/公開」ボタンの状態遷移くらいです。なお「案件詳細」は 2026-07-17 から**アサインする案件を選ぶ入口**に変わり、案件を選ぶと本物の「手動アサイン」画面へ進みます。

### 5-1. アサイン表（`/assign-sheet`）
**何のための画面か**：現場の「東京アサイン表」をそのまま画面にしたものです。1案件を縦長カードにして、案件情報と割り当てメンバー（名前＋ポジション）を一緒に見られます。**この画面から割り当ての編集・保存もできます**。

**使い方の手順**
1. 左上のプルダウンで月を選ぶ（その月のカードが横に並ぶ）
2. 検索ボックスでコンテンツ・顧客・代理店名で絞る
3. 「人数が足りない案件だけ」で不足カードだけ表示
4. カード上で担当・巡回・役割・兼任・備考を直接編集（その場で保存されます）
5. スクロールしてもカードの頭（日付・案件名）は上に残る

### 5-5. 手動アサインの保存（`/project-assign`）
**何のための画面か**：案件1件について、スタッフ名簿から人を選んで**本当にアサインをDBに保存する**画面です。ここで保存した内容は稼働状況・マイページ・スタッフ画面などに本物データとして反映されます。案件一覧の「アサイン」から開きます。

**使い方の手順**
1. 案件ヘッダーで内容を確認
2. アサインしたい人の**「役割」を選ぶと自動でアサイン（チェックが付く）**。役割を決めずにアサインしたいときはチェックだけ入れてもOK
3. 必要に応じて各人に「担当メモ」「巡回」「備考（一言）」「＋兼任（サブ役割）」を入力
4. 「この日 希望・稼働可 の人だけ」チェックや名前検索で候補を絞る
5. 上の「選択◯/必要◯名」で人数を確認
6. 下の「仮で保存（調整中）」または「確定で保存」を押す

**入力欄のポイント**
- **備考（一言）**：担当メモとは別の自由記入欄です。当日の細かな連絡などに使えます。
- **＋兼任**：1人が2役（例：D兼OP、OP兼FC）を担うときに選びます。人数は1人のままで、ポジションの枠は主役割と兼任の両方に1つずつ数えます。
- **「できる役割」バッジ**：D・MC・OP・軍師 だけ表示します（FC・CK・受付は全員できる/不要なので出しません）。OPは名簿の設定に応じて「OP（オンライン）」「OP（リアル）」「OP（オ/リ）」と分けて出ます（未設定は「OP（音響）」）。

**注意**
- **上書き保存**です。チェックを外した人のアサインは消えます。複数日案件（本番・予備日・リハ）は別々に保存します。
- Dは基本1案件につき1名です（自動仮置きもD枠は上限1で置きます）。
- ダブルブッキング（同日別案件）・NGペア・月20件超・人数不一致は**すべて「警告」で、保存はできます**（強制的には止めません）。
- 開催日が未設定の案件は保存できません（日付を先に入れてください）。

## 6. 通知・集計・在庫

### 6-1. 人数確定リマインド（`/count-reminder`）
**何のための画面か**：開催2週間前を迎えた案件を自動で拾い、「参加人数を確定してください」というお知らせを、営業担当とディレクター（D）へチャットワークで一括連絡します。Dには期限つきタスクも付きます。一度送った案件は二度送りません。

**使い方の手順（推奨の順番）**
1. 「③件数だけ確認（送らない）」で対象件数を確認
2. 「②テスト送信」でテスト用ルームに送り、文面・宛先を確認
3. 問題なければ「④本番送信」で本番ルームへ（強い確認ダイアログが出ます）

**注意**
- 本番送信には**チャットワークの鍵（トークン）とルームIDが設定済み**であることが必要です（未設定だと送信ボタンは押せません。件数確認は鍵なしでも可）。
- 送信対象は「開催まで14日以内・未開催・本番日」の案件だけ（予備日・リハは対象外）。
- **一度本番送信した案件は「送信済み」になり二度は送られません。テスト送信は重複防止にカウントされません**（テストしても本番はまだ送れます）。
- Dへのタスク期限は「実行日から3営業日後（土日を飛ばす）の18:00」。祝日は未対応。

### 6-2. 謎解きの紙 在庫（`/paper-stock`）
**何のための画面か**：謎解き系コンテンツで使う「紙」が、これから何枚必要で、いま何枚あるか（不足していないか）を見る画面です。案件データから必要枚数を自動計算し、用意した枚数（入庫数）だけを人が入れます。

**使い方の手順**
1. 「在庫一覧」でコンテンツごとの必要数（今後）・消費数（開催済み）を確認
2. 「入庫数（手入力）」に、実際に用意した枚数を入れる
3. 「入庫数を保存」を押す
4. 「過不足」列が赤字（マイナス）なら、その枚数だけ追加印刷

**計算のしくみ**
- 必要枚数 ＝ チーム数 × 1チームあたり枚数
- チーム数が未入力の案件は「お客様人数 ÷ 6人」で自動推定（明細に★印）
- 在庫数 ＝ 入庫数 − 消費数／過不足 ＝ 在庫数 − 必要数(今後)

**注意**：対象は「マスタ管理」で「紙」チェックを付けたコンテンツだけ。オンライン開催・下書きは集計に含みません。自動計算されるのは必要数・消費数で、手入力は入庫数だけです。

### 7-4. Administratorコンソール（`/admin-console`）
**何のための画面か**：Administratorだけができる作業を集めた画面です。メインは「社員の権限を変える（昇格・降格）」。**Administratorのときだけ**メニューに出ます。

**使い方**：「権限の変更」表で対象社員のプルダウンを選び「保存」。

**安全装置（注意）**
- スタッフはこの表に出ません（権限は「スタッフ」固定）。
- 自分自身のAdministrator権限は外せません。
- 最後のAdministrator（残り1人）は降格できません（先に別の人をAdministratorに）。

### 7-5. 共通設定（`/settings`）
**何のための画面か**：全員に効く共通設定です。主に①アサインMTG日の予定表の登録、②危険日（手動指定）の管理、③マスタ管理への入口と件数確認。

**MTG日の使い方**
1. 「MTG日を追加」で日付を選び「追加」（先の月ぶんもまとめて）
2. 入れたい日付をすべて入れる
3. 最後に「この予定表を保存する」を押す（**「追加」だけでは保存されません**）

**なぜ必要か**：「今日までで一番新しいMTG日」が自動で基準になり、それより後に登録された案件が「追加案件」扱いになります（毎月の手直しを減らすため）。

**危険日（手動指定）の使い方（2026-07-17 追加）**
- 大型案件の日付が一覧で出ます。加えて、**手で「危険日」を追加・削除**できます。
- ここで指定した日付は、ダッシュボードなどの危険日判定に自動で加わります（自動判定だけでは拾えない日を人が足せる、という位置づけ）。

### 7-6. マスタ管理（`/masters`）
**何のための画面か**：案件登録やアサインで使う「選択肢の元データ（マスタ）」を管理します。①コンテンツ、②拠点（事務所）、③ポジション（役割）。ここを直すと全画面の選択肢に反映されます。

**コンテンツ**：各行で名前・分類・「紙」（謎解きシートが要るか）・「枚/組」・「有効」を編集。「必要人数」ボタンで規模別の必要人数設定へ。新規行から追加。「すべて保存」でまとめて保存。
**拠点**：名前・並び替え（▲▼）・有効を編集。新規行から追加。
**ポジション**：D／SD／OP／MC／FC／CK／軍師・サポーター／受付の一覧（**表示のみ・編集不可**）。

**注意**：コンテンツ・拠点の「**削除」はAdministratorのみ**（他の人には削除ボタンが出ません）。追加・編集は社員以上なら可能。ポジションはシステムの土台なので画面から変更できません。
